## Structure
Each folder is a standalone, runnable project with its own README, dependency file, and (from Week 7 onward) Dockerfile. No folder depends on another being present.

## Why this repo exists
Recruiters and interviewers judge Forward Deployed Engineer candidates on shipped, explainable work more than credentials. This repo is the paper trail: a project every 1-2 weeks, a bigger deployed system at the end of every phase, and three interview-ready capstones by the end.
